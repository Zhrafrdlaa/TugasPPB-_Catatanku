# TugasPPB-_Catatanku
Aplikasi CatatanKu merupakan project tugas individu Flutter untuk merancang dan mengimplementasikan antarmuka pengguna (UI) aplikasi catatan harian dengan desain yang sederhana, modern, dan mudah digunakan. Project ini mencakup lima halaman utama, yaitu Splash Screen, Login Statis, Beranda, Tambah Catatan, dan Detail Catatan.
